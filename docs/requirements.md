# 需求与功能范围

应用面向 Windows 11 x64 上使用 Chrome 或 Edge 的单机用户。用户选择普通话或英语，停止浏览器录音或提交本地音频后，服务在本机 CPU 上转写，并将文本和耗时返回页面。

| 功能 | 行为 |
| --- | --- |
| 录音 | 请求麦克风权限，显示录音状态和计时，允许手动停止，60 秒自动停止。停止后提交一次录音，完成或出错后可再录。 |
| 文件上传 | 接受 WAV 和浏览器录制的 WebM。上传和录音复用同一识别接口。无效文件收到可理解的提示。 |
| 本地识别 | 手动选择中文或英文，使用本地开源模型做单语转写。模型权重准备好后可离线使用。 |
| 识别结果 | 识别过程中显示进度状态，结果区展示文本、语言、音频时长和服务端处理耗时，支持复制。 |
| 实时预览 | 约 4 秒独立音频分片，停止前持续更新文字，停止后用完整录音生成一次终稿。 |
| 异常处理 | 权限拒绝、无可用设备、录音中断、文件非法、模型加载或推理失败均给出对应提示。静音可以返回空文本。 |

## 接口与边界

- `GET /` 提供网页。模型就绪时 `GET /health` 返回 HTTP 200 和 `{"status":"ok"}`。
- `POST /api/transcribe` 接收 multipart 的 `file` 和 `language`，语言取值为 `zh` 或 `en`，成功响应包含 `text`、`language`、`duration_seconds`、`processing_seconds`。
- 文件上限为 10 MiB。浏览器以 60 秒为录音上限，服务端解码允许 0.5 秒收尾偏差。浏览器长时间挂起导致录音明显超时，服务端会拒绝并提示分段。
- 首次准备模型权重需要网络。默认预加载模型，缓存准备完成后可以离线启动。浏览器录音使用 localhost 的安全上下文。
- 已实现近实时转写；自动语言检测、登录和历史记录不在当前范围内。
